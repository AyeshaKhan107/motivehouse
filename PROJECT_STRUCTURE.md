# Project structure

- `app/page.tsx` — Home page
- `app/services/graphic-design/page.tsx` — Graphic design service
- `app/services/social-media/page.tsx` — Social media service
- `app/services/bookkeeping-accounting/page.tsx` — Bookkeeping and accounting service
- `app/services/tax-preparation/page.tsx` — Tax preparation service
- `app/globals.css` — Full responsive styling and burgundy/cream/black palette
- `components/SiteHeader.tsx` — Responsive navigation
- `components/SiteFooter.tsx` — Footer and quick links
- `components/HomePage.tsx` — Homepage sections
- `components/ServicePage.tsx` — Shared service page component
- `components/ContactForm.tsx` — Email-app contact enquiry form
- `lib/site-data.ts` — Shared service copy and page data
- `public/images/` — Temporary reference crops for visual backgrounds
